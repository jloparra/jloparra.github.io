# TrackIU demo — privacy and limitations

This demo is a static site published via GitHub Pages. It is not a production system.

## Data and environment

- Only synthetic demo data is used.
- No real names, emails or health data should be entered.
- State is stored locally via `localStorage`.
- There is no backend, database or encryption of application data.

## What a real pilot would require

- Backend and database with tenant isolation.
- Authentication and server-side authorization.
- Explicit consent capture and versioning.
- Minimisation and retention policies.
- Audit logs and access control.
- Legal review and DPIA when applicable.

This document is a placeholder and does not constitute legal advice.
