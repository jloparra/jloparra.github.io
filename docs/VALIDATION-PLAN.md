# TrackIU demo — validation plan with coaches

This document suggests how to validate the decision-loop demo with real coaches.

## Suggested script

1. Observar sin explicar.
2. Pedir que encuentren la clase de hoy.
3. Pedir que revisen tres atletas ficticios.
4. Pedir que modifiquen una propuesta.
5. Preguntar qué información faltó.
6. Preguntar si lo usarían antes de una clase real.
7. Medir tiempo y errores.
8. Registrar lenguaje espontáneo del coach.
9. No enseñar futuras funciones antes de terminar la prueba.

## Metrics (hypotheses, not validated)

- Tiempo hasta la primera decisión.
- Número de errores al interpretar semáforo y propuestas.
- Número de veces que el coach busca contexto fuera de la herramienta.

These metrics are hypotheses for future validation, not success criteria yet.
